Pilyo Bar & Billiards – Integrated Table Management System

Client project · Next.js, Supabase, TanStack

A full venue management system for a billiards bar. It includes table reservations, online payments through GCash, Maya and cards using the Xendit API with webhook handling, an admin-approved refund workflow, tournament brackets, 1v1 challenge matches with a ranking system, and a reports section for reservations, table usage and analytics.

Freelance project · Supabase, PostgreSQL

A website and records system for the 4-H Club Federation of Bicol. It uses Supabase Auth and PostgreSQL Row-Level Security so each coordinator across six provinces sees only their own data.

Personal project · ESP32, Flutter

An IoT system that monitors and automates a greenhouse using ESP32 sensor nodes connected through ESP-NOW, with live dashboards in Node-RED, InfluxDB and Grafana. Its companion Flutter app, AgriLink Farm Tracker, helps farmers in the Bicol Region and works offline.
